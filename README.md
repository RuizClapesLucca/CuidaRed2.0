## De qué trata el proyecto

CUIDARED conecta a personas que necesitan un servicio de cuidado (**solicitantes**) con personas que lo ofrecen (**prestadores**). El solicitante publica una solicitud, los prestadores se postulan y el solicitante elige a quien lo atenderá.

El sistema también cuenta con registro verificado por correo, inicio de sesión con doble factor, reportes entre usuarios y un panel para que los **administradores** revisen reportes y gestionen cuentas.

## Tecnologías

Node.js, Express, Supabase (PostgreSQL), Render y Vercel.

## Cómo ejecutarlo

```
npm install
npm start
```

Se necesita un archivo `.env` con las variables de entorno. Los pasos de publicación están en [DEPLOY.md](DEPLOY.md).
